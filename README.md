# 灵台自动连砍

一个用于灵台页面的油猴脚本。它会按设定的时间间隔自动调用页面自带的“连砍 10 刀”按钮，直到当天斧力归零。

## 使用文档

### 快速安装

1. 先安装浏览器脚本管理器：
   - [Tampermonkey](https://www.tampermonkey.net/)
   - [Violentmonkey](https://violentmonkey.github.io/)
2. 点击下面的 Raw 安装链接：

   [点击安装灵台自动连砍脚本](https://raw.githubusercontent.com/zxl56123/lingtai-auto-chop/main/lingtai-auto-chop.user.js)

3. 油猴管理器会打开脚本安装确认页，点击“安装”即可。
4. 打开或刷新灵台页面：<https://k40.shengqainbang.cn/lingtai>
5. 页面右下角出现“自动连砍”面板后即可使用。

> 如果点击 Raw 链接后只显示源代码，请确认已安装并启用 Tampermonkey 或 Violentmonkey，然后在脚本管理器中选择“从文件或剪贴板安装”。

### 基本操作

1. 在面板中设置“点击间隔”，默认是 `1500ms`。
2. 点击“开始连砍”。
3. 脚本会自动调用页面原有的“连砍 10 刀”按钮。
4. 面板会显示剩余斧力、本次连砍次数和运行用时。
5. 斧力显示为 `0` 后会进入容错模式，最多额外连砍 10 次。
6. 按钮连续 5 次禁用后，脚本会自动结束。
7. 第一次点击“停止”会冻结任务；任务停止后再次点击“停止”会重置次数和用时。
8. 面板顶部标题栏可以拖动，位置会自动保存。
9. 点击面板右上角的刷新图标可检查更新（悬停提示“检查更新”）；检查时图标旋转，发现新版本时会打开 Raw 安装页。
10. 连砍过程中会检查仓库容量；装备数量达到 **70 件**时自动调用“一键分解（蓝及以下）”，提前清理以免影响装备掉落。分解后仍达到 70 件会暂停任务并显示红色提示，手动处理后点击“开始连砍”继续。

## 功能

- 自动点击“连砍 10 刀”按钮
- 可设置点击间隔，默认 `1500ms`
- 最小间隔为 `300ms`，用于降低触发网站防抖的概率
- 动态读取页面上的“斧力 当前值 / 上限”
- 斧力归零后自动停止
- 检测按钮忙碌状态，避免上一批请求未完成时重复点击
- 提供右下角悬浮控制面板
- 支持鼠标和触摸拖拽面板
- 自动保存点击间隔和面板位置
- 支持窗口大小变化时自动调整面板位置
- 支持移动端窗口布局
- 实时记录本次任务运行用时，停止或完成后保留最终用时
- 第一次点击“停止”冻结本次用时，任务停止后再次点击可重置统计
- 斧力显示为 0 后进入容错模式，最多额外连砍 10 次
- 容错模式下按钮连续 5 次禁用后自动结束
- 支持面板内检查 GitHub 最新版本并打开 Raw 更新页
- 自动监测装备仓库容量，达到 70 件时分解蓝色及以下装备
- 分解后仍达到 70 件时暂停连砍并显示红色人工处理提示

## 参数说明

| 参数 | 默认值 | 说明 |
| --- | ---: | --- |
| 点击间隔 | `1500ms` | 两次调用“连砍 10 刀”之间的等待时间 |
| 最小间隔 | `300ms` | 输入低于该值时会自动按 `300ms` 处理 |
| 自动分解阈值 | `70 件` | 达到该数量即清理蓝色及以下装备；实际仓库容量低于 70 时按实际容量触发 |

点击间隔和面板位置保存在当前网站的 `localStorage` 中，仅在当前浏览器配置中生效。

## 工作原理

脚本通过油猴管理器注入到目标站点，并在进入灵台页面时显示面板。匹配范围为：

```text
https://k40.shengqainbang.cn/*
```

脚本会监听网站的单页路由切换，因此从仪表盘点击进入“灵台”时也可以正常显示面板。

连砍操作使用浏览器原生 DOM API 查找页面已有的“连砍 10 刀”按钮，并调用按钮的 `click()` 方法。

“检查更新”按钮使用油猴提供的 `GM_xmlhttpRequest` 读取 GitHub Raw 文件中的 `@version`。发现远程版本更高时，会打开 Raw 地址交给油猴管理器进行安装确认。

仓库监测使用灵台的 `/api/v1/game/status` 接口读取 `bag_used` 和 `bag_cap`；装备数量达到 70 件时调用 `/api/v1/game/salvage-batch`，参数为 `max_color: "blue"`，与页面“一键分解（蓝 及以下）”按钮一致。分解后再次检查数量，低于阈值才继续连砍，否则暂停并显示红色提示。若实际容量低于 70 件，清理阈值自动采用实际容量。

斧力通过页面上类似下面的文本动态识别：

```text
斧力 2060 / 2060
```

因此每日斧力上限变化时不需要修改脚本。

控制面板由脚本动态创建，样式使用自定义 CSS。脚本没有使用 jQuery、React、Vue 或其他第三方运行库。

## 注意事项

- 这是一个浏览器端自动化脚本，需要用户自行安装油猴管理器。
- 脚本只会点击页面已有的“连砍 10 刀”按钮，不保证网站规则或页面结构永久不变。
- 如果网站修改按钮文字、页面结构或斧力显示格式，脚本可能需要同步调整。
- 建议根据网站实际防抖规则设置合适的点击间隔，不要使用过低的间隔。
- 脚本不会在页面加载后自动开始，必须手动点击“开始连砍”。
- 使用脚本前请确认符合目标网站的使用规则。
